# ICD: EDF + ESC

**Endpoints:** EDF branch (XT60) → Skywalker 50A V2 ESC → JFtech 64 mm EDF. Throttle signal comes from Teensy pin 2.
**Status:** Preliminary

## Connections

| # | From | To | Wire | Connector | Notes |
|---|---|---|---|---|---|
| E1 | XT60 female (supply) | ESC power input (+/−) | ESC leads (12–14 AWG) | XT60 male on the ESC | |
| E2 | ESC motor A/B/C | EDF motor leads | ESC/EDF leads | 3.5 mm bullets | **Swap any two phases if the fan spins the wrong way** (air must blow out the exhaust) |
| E3 | ESC signal (white/yellow) | Teensy pin 2 | 22–26 AWG | Dupont / servo plug | |
| E4 | ESC signal GND (black/brown) | Teensy GND | 22–26 AWG | Dupont / servo plug | **Required** reference |
| E5 | ESC BEC +5 V (red) | — | — | — | **Leave disconnected.** Pull the pin from the plug or insulate it. |

## Signal

| Parameter | Value |
|---|---|
| Type | Standard RC PWM, generated by the Teensy `Servo` library |
| Frame rate | 50 Hz |
| Pulse | 1000 µs = stop, 2000 µs = full throttle [VERIFY after calibration] |
| Logic level | 3.3 V (Teensy). Most ESCs accept it [VERIFY: if the ESC won't arm, add a 3.3 → 5 V buffer]. |
| Signal loss | ESC stops the motor (built-in protection) |

## Throttle limit

The EDF can pull ~50 A at full throttle; F1 is 15 A. The firmware clamps throttle to `THROTTLE_MAX` (`config.h`), which starts at **0.25**. Raise it only in small steps, with an inline watt meter, until steady current is ≈ 12 A. Record the result here:

## Bring-up procedure (fan restrained, guard on, nobody in line with the fan)
1. **Throttle calibration:** follow the Skywalker manual (power up at max signal, wait for beeps, drop to min). Run `firmware/tests/esc_test` to generate the signals.
2. Check spin direction at the lowest throttle that turns the fan.
3. Step up the throttle cap while watching the watt meter.
4. Confirm the firmware `stop` command and a USB unplug both stop the fan.

## Open items
- Confirm the ESC's connectors and lead gauges on receipt.
- Check the ESC's default brake setting; disable the brake.
